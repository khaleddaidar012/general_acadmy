# أكاديميتك — General Academy

نسخة عرض مستقلة لموقع ونظام إدارة أكاديمية قرآن وتعليم عبر الإنترنت، بواجهتين عربية وإنجليزية. تشمل إدارة الطلاب والمعلمين والصلاحيات، الجدول الأسبوعي، حضور الحصص، تقدم الحفظ، تقارير أولياء الأمور PDF والنسخ الاحتياطي.

هذه نسخة للتصوير والعرض: بيانات التواصل توضيحية، وإرسال البريد والدفع الحقيقي معطلان. لا تحتوي قاعدة بيانات أكاديمية فعلية أو مفاتيح خدمات أو كلمات مرور منشورة. الأسعار المقترحة ومراجعها موجودة في [PRICING-BENCHMARK.md](PRICING-BENCHMARK.md).

## التشغيل المحلي

يتطلب Node.js 24 وnpm.

```powershell
npm ci
Copy-Item .env.example .env.local
```

اكتب كلمة مرور خاصة من 12 حرفًا على الأقل في `ACADEMY_ADMIN_PASSWORD` داخل `.env.local`، ثم:

```powershell
npm run dev
```

الموقع: http://localhost:3002/ar — الإدارة: http://localhost:3002/ar/dashboard

عند تسجيل الدخول لأول مرة تنشأ قاعدة محلية وحساب المدير وفق البريد وكلمة المرور المحددين في `.env.local`. الحساب الافتراضي في القالب هو `admin@academy.example`؛ كلمة المرور لا تُضبط تلقائيًا ولا توجد كلمة مرور عامة ثابتة.

## بيانات وهمية للتصوير — اختياري

قبل تشغيل الخادم لأول مرة، وعلى قاعدة جديدة فقط:

```powershell
$env:DEMO_PASSWORD="ضع-هنا-كلمة-مرور-خاصة-بالعرض"
npm run seed:demo
Remove-Item Env:DEMO_PASSWORD
npm run dev
```

استخدم نفس القيمة في `ACADEMY_ADMIN_PASSWORD` للتناسق. حسابات العرض تستخدم كلمة المرور التي اخترتها في `DEMO_PASSWORD`:

| الدور | البريد |
|---|---|
| مدير | admin@academy.example |
| مسؤول نظام | manager@academy.example |
| معلم | teacher1@academy.example |
| طالب | student1@academy.example |
| ولي أمر | parent1@academy.example |

تُنشأ 6 حسابات معلمين، و12 طالبًا مؤكدًا، وحساب طالب ينتظر التأكيد، و3 أولياء أمور، ومدير ومسؤول نظام، مع 156 حصة وسجل تقدم تجريبي. التواريخ مرتبطة بوقت إنشاء البيانات. يرفض الأمر استبدال قاعدة موجودة. إذا شغّلت الخادم قبل الأمر، استخدم نسخة مشروع جديدة للتجربة بدل حذف بياناتك.

## الملفات المحلية

قاعدة البيانات داخل `.data/academy_demo.sqlite`. المجلدات `.data` و`.local` و`.next` و`node_modules` وملفات `.env.local` مستبعدة من المستودع. لا تعتمد نسخة تنزيل جديدة على مكتبات أو مجلدات من مشروع آخر؛ `npm ci` يثبت جميع المكتبات محليًا.

## الفحص والبناء

```powershell
npm run check
npm run build
npm start -- --port 3002
```

الخطوط محلية لتعمل الواجهة أثناء التصوير دون تحميل خطوط من خدمات خارجية. تراخيص الخطوط داخل `public/fonts`.

## Cloudflare

إعدادات OpenNext وWorker وD1 وR2 موجودة كنقطة بدء، وليست إعدادات نشر جاهزة لحسابك. قبل الاستخدام الفعلي اضبط معرف D1 والحاوية الخاصة وربط الخدمة في `wrangler.jsonc`، وطبّق المهاجرات، واضبط الأسرار وكلمات المرور، وراجع تعطيل خدمات الدفع والبريد في نسخة العرض. لا تستخدم حسابات العرض في خدمة فعلية.

النسخ اليومية تحتاج R2 خاصًا وCron عند النشر. الحفظ المحلي من المتصفح يحتاج اختيار مجلد وإذنًا لكل جهاز، ويعمل أثناء فتح النظام. ملفات الاستعادة تكتب إلى قاعدة جديدة ولا تستبدل قاعدة قائمة.
